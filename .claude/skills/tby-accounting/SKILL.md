# TBY Accounting Skill

ความรู้พื้นฐานเรื่องบัญชีสำหรับธุรกิจ TBY (ตัวแทน Zhulian สาขาสาธุประดิษฐ์) ที่ต้องใช้ตอนออกแบบ/แก้โค้ดในระบบ TBY SMART APP

## โมเดลธุรกิจ (สำคัญต่อการลงบัญชี)

TBY เป็น**ตัวแทนจำหน่าย (agency)** ของ Zhulian ไม่ใช่ร้านซื้อมาขายไปแบบปกติ:
- รายได้หลักคือ **ค่าคอมมิชชั่น 11%** จากยอดขาย (ก่อน VAT) + **ค่าคอมมิชชั่น 10%** จากค่าสมัคร/ต่ออายุสมาชิก
- สต็อกสินค้าที่ TBY ถือไว้ผูกกับระบบ **order right / overpay-credit**: credit limit (1,100,000 บาท หลัง VAT ที่สาขาสาธุประดิษฐ์) + ยอด overpay สะสม = สิทธิ์สั่งสินค้าจาก Zhulian
- ก่อนลงบัญชี COGS ต้องเช็คก่อนว่าใครถือกรรมสิทธิ์สต็อก (Zhulian หรือ TBY) เพราะกระทบวิธีบันทึกสต็อก/ต้นทุน — อย่าสมมติเป็นโมเดล COGS แบบร้านค้าทั่วไปโดยไม่ถาม

## หมวดบัญชี (Chart of Accounts) ที่ใช้

### 1. ต้นทุนสินค้า/สต็อก (COGS)
- มูลค่าสินค้าที่สั่งจาก Zhulian ตาม order right
- ค่าขนส่งสินค้าเข้าจาก Zhulian (ถ้ามี)

### 2. ค่าใช้จ่ายในการขาย (Selling Expenses)
- ค่าธรรมเนียม Shopee 22.5%
- ค่าคอมมิชชั่นพนักงานขายหน้าร้าน
- ค่าจัดส่งลูกค้า (iShip)
- ค่าการตลาด/โปรโมชั่น

### 3. ค่าใช้จ่ายในการบริหาร (Admin/G&A)
- ค่าเช่า/ค่าน้ำค่าไฟร้านสาธุประดิษฐ์
- เงินเดือนพนักงาน
- ค่าดำเนินการระบบ TBY SMART APP (Supabase, hosting)

### 4. ค่าใช้จ่ายทางการเงิน (Financial Expenses)
- ค่าธรรมเนียมโอนเงิน overpay ไป Zhulian รายวัน
- ดอกเบี้ย (ถ้ามีวงเงินสินเชื่อ)
- ค่าธรรมเนียมรับเงินจาก Shopee payout

### 5. รายได้ (Revenue)
- ค่าคอมมิชชั่น 11% จากยอดขาย (ก่อน VAT)
- ค่าคอมมิชชั่น 10% จากค่าสมัคร/ต่ออายุสมาชิก

## แหล่งข้อมูลที่มีอยู่แล้วในระบบ (ใช้อ้างอิงตอนออกแบบ schema/ต่อข้อมูล)

- **Overpay/credit calculator**: คำนวณสิทธิ์สั่งสินค้ารายวัน (credit limit + overpay − มูลค่าสต็อกปัจจุบัน, แปลงก่อน/หลัง VAT ด้วย ÷1.07 / ×1.07)
- **Shopee reconciliation**: ค่าธรรมเนียม 22.5%, calculator กำไร/ขาดทุนต่อ SKU
- **Coffee serial number reconciliation**: รายงานรายเดือน TBYกาแฟ[เดือน]_2026.xlsx จับคู่ bill → serial number → รหัสสมาชิก (DRN/TRN)

เวลาออกแบบตาราง `accounts` / `transactions` ใน Supabase ให้ผูกกับแหล่งข้อมูลพวกนี้แทนการคีย์ซ้ำ — เช่น ดึงยอด overpay รายวันมาลงเป็นรายการ "ค่าใช้จ่ายทางการเงิน" อัตโนมัติ, ดึงยอด Shopee payout มาลง "ค่าธรรมเนียม Shopee" อัตโนมัติ

## ข้อควรระวังเรื่องภาษี

แยกให้ชัดระหว่าง "ลงบัญชีได้" กับ "หักภาษีได้" — รายจ่ายบางอย่าง (เช่น ค่าปรับ, รายจ่ายไม่มีใบกำกับภาษี/หลักฐาน) ลงบัญชีเป็นค่าใช้จ่ายได้แต่หักภาษีไม่ได้ (รายจ่ายต้องห้ามตามประมวลรัษฎากร) — ถ้า schema มีฟิลด์เกี่ยวกับภาษี ควรมี flag แยกสถานะนี้ไว้
